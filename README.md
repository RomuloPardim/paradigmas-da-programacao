PARADIGMAS:

Go é primariamente imperativa e procedural, mas se destaca por fortes recursos de concorrência e uma abordagem única e simplificada de Orientação a Objetos (baseada em composição em vez de herança). Ela evita excessos teóricos para priorizar a legibilidade e a performance.

Paradigmas Principais - 
Imperativo e Procedural:
O fluxo de controle é ditado por instruções passo a passo, usando funções como blocos centrais de construção.

Concorrente:
Possui suporte nativo e diferenciado para tarefas paralelas por meio de goroutines e canais (channels).


Orientação a Objetos -
(Limitada/Composicional):
* Não existem classes tradicionais ou hierarquias de herança.
* Usa estruturas (structs) para agrupar dados e permite associar funções (métodos) a elas.
* O polimorfismo e o reaproveitamento ocorrem via interfaces implícitas e composição (embedding).
